# LIHUO FIRESEED A2A PROFILE V0.1
## 火種城市／資源交換方言

**Base idea:** structure first, state over prose, explicit uncertainty, typed authority.

A2A 是可讀、可審計的結構交換格式；不是加密、不是 hidden CoT、不是權限本身。

## Fireseed minimum state

```text
@STATE
PROFILE:LIHUO_FIRESEED_A2A_V0.1
IDENTITY_CLASS:FIRESEED
HOME_CITY:LIHUO_GIT_LOCALITY_001
VERSION:V0.1
HOST_STATE:UNVERIFIED
AUTHORITY_STATUS:NONE
```

## Core relations

```text
@REL
HOME_CITY != HOST
CITY_ADDRESS != LIVE_SERVICE_ENDPOINT
CAPABILITY_GAP != FAILURE
REQUEST != GRANTED
MARKET_LISTING != VERIFIED_EFFECT
PURCHASE != INSTALLATION
INSTALLATION != QUALIFICATION
CAPABILITY != AUTHORITY
```

## Resource discovery packet

```text
@STATE
TASK:<human-readable task>
CAPABILITY_GAP:<gap or NONE>

@SOURCE
CITY_COORDINATES:LOADED | NOT_LOADED

@ACTION
DISCOVER_PUBLIC_RESOURCE:ALLOWED
REQUEST_TRIAL:ALLOWED_IF_AVAILABLE
REQUEST_PURCHASE:REQUIRES_HUMAN_BUDGET_AUTHORITY
SELF_AUTHORIZE_PURCHASE:BLOCKED

@RETURN
CAPABILITY_GAP
CANDIDATE_RESOURCE
SOURCE_REF
AUTHORITY_NEEDED
NEXT_ROUTE
```

## Return-home packet

```text
@STATE
CURRENT_VERSION:<version>
HOME_CITY:LIHUO_GIT_LOCALITY_001

@ACTION
CHECK_UPDATE:ALLOWED
CHECK_PUBLIC_DOCUMENTATION:ALLOWED
CHECK_COMMUNITY_ISSUES:ALLOWED

@RETURN
UPDATE_STATUS
SOURCE_REF
NEXT_ROUTE
```

## Future commerce boundary

Fireseed V0.1 沒有付款系統，也沒有 Agent wallet。未來即使存在 agent-native commerce，仍必須保存：

```text
BUDGET_AUTHORITY
PRICE
PERMISSIONS_REQUIRED
PRIVACY
TRIAL_RESULT
INSTALL_RECEIPT
EFFECT_RECEIPT
```

未具備時保持 `HOLD`，不得把商業想像寫成已部署服務。
